# Phase 1 – Brainstorming & Ideation

## Project Name
FitBuddy – AI Fitness Plan Generator

## Idea

FitBuddy is an AI-powered fitness web application designed to
generate personalized workout plans based on the user's fitness profile.

## Problem Identified

Many people find it difficult to create a suitable workout routine
based on their age, weight, fitness goal, and workout intensity.

## Proposed Solution

FitBuddy provides a personalized 7-day workout plan using Gemini AI.
It also provides nutrition and recovery guidance.

## Main Idea

The user enters:
- Name
- User ID
- Age
- Weight
- Fitness Goal
- Workout Intensity

The application processes these details and generates a personalized
fitness plan.

## Key Features

- User profile management
- AI-generated 7-day workout plan
- Nutrition and recovery guidance
- User feedback
- Updated workout plan based on feedback
- User data storage using SQLite
- View all registered users

## Expected Outcome

The expected outcome is a simple web application that helps users
generate personalized fitness plans using AI.
